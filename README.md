# SP

Repozytorium służy do przechowywania narzędzi i materiałów technicznych związanych z SharePoint, w szczególności:

- skryptów PowerShell,
- raportów diagnostycznych,
- dokumentacji technicznej.

Przed dodaniem raportu sprawdź, czy nie zawiera haseł, tokenów, danych osobowych ani poufnych informacji o środowisku. Dane dostępowe i pliki z sekretami przechowuj poza repozytorium.
